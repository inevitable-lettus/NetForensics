# Help

| Page | Use it when |
|---|---|
| [Troubleshooting](troubleshooting.md) | A command printed an error, a timestamp stays `PENDING`, or a verdict is not what you expected. |
| [FAQ](faq.md) | You have a question about what the output means or whether it can be trusted. |
| [Known limitations](known-limitations.md) | You want to know where the detectors are weak and which false positives to expect. |

If something is not covered, open an issue at
[github.com/inevitable-lettus/NetForensics/issues](https://github.com/inevitable-lettus/NetForensics/issues) with the
command, its exact output and the exit code.
